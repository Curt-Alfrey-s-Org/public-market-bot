## 📝 Documentation Standards

### Active Documents
- Kept in repository root or `docs/guides/`
- Updated with feature changes
- Referenced in main README
- Maintained for accuracy

### Archived Documents
- Listed in `ARCHIVE.md`
- Moved to `docs/archive/`
- Preserved for reference
- Not actively updated

## 🔄 Document Lifecycle

1. **Creation:** New features get documentation
2. **Active:** Document is current and maintained
3. **Superseded:** Replaced by better documentation
4. **Archived:** Moved to archive for reference

## 🤝 Contributing to Documentation

### When to Update Docs
- New feature added
- Feature behavior changed
- Bug fix affects user experience
- Configuration options changed
- Breaking changes introduced

### How to Update
1. Update relevant guides in root or `docs/guides/`
2. Keep changes clear and concise
3. Add examples where helpful
4. Update table of contents if needed
5. Link between related documents

### Documentation Style
- Use clear, simple language
- Include code examples
- Add screenshots for GUI features
- Structure with headers and lists
- Keep README.md link updated
