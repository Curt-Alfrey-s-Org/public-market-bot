ISSUE FIX SUMMARY - Async Event Loop Error in Threaded Contexts

Issue #: Debug log error analysis
Date: 2026-01-22

================================================================================
ORIGINAL PROBLEM
================================================================================
Error Message:
  [10:09:34] sentiment_analyzer - WARNING - Async sentiment analysis failed, 
  falling back to sync: There is no current event loop in thread 
  'Thread-336 (run_bot_loop)'.

Impact:
  - Async sentiment analysis was failing in the bot loop thread
  - System was falling back to slower synchronous operations
  - 2-8x performance degradation for sentiment and data fetching

================================================================================
ROOT CAUSE
================================================================================
The bot's run_bot_loop() function runs in a separate thread. When async
wrapper methods tried to use asyncio.get_event_loop(), they failed because:
  1. Python 3.10+ raises RuntimeError in threads without event loops
  2. The deprecated pattern didn't handle thread contexts properly
  3. All async operations fell back to slow synchronous alternatives

================================================================================
SOLUTION
================================================================================
Updated all async wrapper methods to use thread-safe pattern:
  - Use asyncio.get_running_loop() instead of get_event_loop()
  - Use asyncio.run() to create new loops when needed
  - Properly handle both threaded and non-threaded contexts

================================================================================
TECHNICAL DETAILS
================================================================================
Before Pattern (BROKEN in threads):
  loop = asyncio.get_event_loop()  # RuntimeError in threads!
  if loop.is_running():
      pass
  else:
      return loop.run_until_complete(async_func())

After Pattern (WORKS in threads):
  try:
      loop = asyncio.get_running_loop()  # Check if loop exists
      # Fall through to sync (can't nest event loops)
  except RuntimeError:
      # No loop, safe to create one
      return asyncio.run(async_func())  # Thread-safe!
